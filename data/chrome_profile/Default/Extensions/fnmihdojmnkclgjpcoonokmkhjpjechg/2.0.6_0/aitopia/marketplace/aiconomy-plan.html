Dual Balance System

Mandatory Anti-Fraud
Why This Is Non-Negotiable: Without separate balances, users can buy credits at bulk discount ($0.0133/credit) and cash out at full rate ($0.02/credit) = 50% instant profit. Platform bleeds money.

Implementation Plan

4 Phases
Phase 0: Foundation 2 weeks
  • Implement Earn vs Spend credit separation
  • Define qualified view (30% watch time, unique/day)
  • Settlement pipeline with pending state
  • Domain registration system for embeds
Phase 1: Premium + Remixes 4 weeks
  • Premium subscription tiers (Creator $9.99, Pro $29.99)
  • Premium Pool monthly distribution by watch time
  • Remix earnings on generation events
  • Creator dashboard: pending → earned → available
  • Cash-out with conversion tiers (verified only)
Phase 2: View Monetization 6 weeks
  • Watch time telemetry pipeline
  • Domain trust verification flow
  • Pre-roll ads (curated/direct sales first)
  • Full 4-pool split distribution
  • Fraud vendor integration
Phase 3: Scale 8 weeks
  • Programmatic ads (if approved)
  • Graph-based fraud detection
  • Creator promotion marketplace
  • API for third-party integrations
