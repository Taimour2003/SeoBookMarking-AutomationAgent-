Core Rules (Anti-fraud)

why this works
Spend vs Earn mandatory
Spend credits run generation and unlock ad-free viewing (not cashable).

Earn credits are minted from ads/premium/remix events and can be cashed out with holds.
Net-based splits after costs
Payouts are calculated on net value (ad fees + CDN + reserves removed). This prevents negative margins and keeps the platform sustainable.
Embeds viral + safe
Embeds can be open for playback, but payouts require registered/verified domains. Unknown domains get views, but no earnings.
