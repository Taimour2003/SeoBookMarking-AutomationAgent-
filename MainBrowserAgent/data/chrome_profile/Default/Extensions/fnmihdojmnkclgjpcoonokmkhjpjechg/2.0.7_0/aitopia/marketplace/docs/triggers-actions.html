Triggers & Actions

Automate agent executions with webhooks, schedules, and action chains.

Overview

External Event → Trigger → Agent Execution → Actions → Next Agent/Webhook
  • Triggers - Start agent executions based on webhooks or cron schedules
  • Actions - Execute after an agent completes (webhook notifications, agent chaining)

Triggers

Webhook Trigger

Create an HTTP endpoint that triggers agent execution.

POST /triggers
Content-Type: application/json
X-Tenant-Id: my-tenant

{
  "name": "GitHub PR Analyzer",
  "type": "webhook",
  "agentId": "code-reviewer",
  "path": "github-pr",
  "secret": "my-webhook-secret-16chars",
  "inputMapping": {
    "fromPayload": {
      "prNumber": "body.pull_request.number",
      "prTitle": "body.pull_request.title"
    },
    "static": {
      "repository": "my-org/my-repo"
    }
  },
  "rateLimit": {
    "windowMs": 60000,
    "maxRequests": 10
  }
}

Schedule Trigger

Run agents on a cron schedule.

POST /triggers
{
  "name": "Daily Report Generator",
  "type": "schedule",
  "agentId": "smart-data-analyzer",
  "cron": "0 9 * * *",
  "timezone": "America/New_York",
  "inputMapping": {
    "static": {
      "task": "Generate daily sales report"
    }
  }
}

Calling a Webhook

POST /webhooks/{path}
Content-Type: application/json
X-Signature: t=1234567890,v1=...
Idempotency-Key: unique-request-id

{
  "your": "payload"
}

X-Signature - HMAC-SHA256 signature (required if secret configured)

Idempotency-Key - Prevents duplicate processing (optional)

Actions

Webhook Action

Send HTTP POST to external URL when agent completes.

POST /actions
{
  "name": "Notify Slack",
  "type": "webhook",
  "agentId": "smart-data-analyzer",
  "webhook": {
    "url": "https://hooks.slack.com/services/xxx",
    "method": "POST",
    "headers": {
      "Content-Type": "application/json"
    },
    "timeoutMs": 10000,
    "retries": 3
  },
  "conditions": {
    "status": ["success"]
  }
}

Agent Chain Action

Trigger another agent with mapped output.

POST /actions
{
  "name": "Analyze then Summarize",
  "type": "agent_chain",
  "agentId": "smart-data-analyzer",
  "agentChain": {
    "targetAgentId": "content-summarizer",
    "inputMapping": {
      "content": "output.analysis",
      "format": "output.metadata.format"
    },
    "async": false,
    "propagateBudget": true
  },
  "conditions": {
    "status": ["success", "partial"]
  }
}

Key Features

HMAC Signatures

Webhooks verified with SHA-256 HMAC for security

Rate Limiting

Configurable per-trigger sliding window limits

Idempotency

Duplicate requests automatically handled

Circuit Breaker

Auto-disable failing webhook actions

Budget Propagation

Share remaining budget across agent chains

Async Execution

Fire-and-forget or wait for completion

Generating Signatures

const crypto = require('crypto');

function signWebhook(payload, secret) {
  const timestamp = Date.now();
  const signedPayload = `${timestamp}.${payload}`;
  const signature = crypto
    .createHmac('sha256', secret)
    .update(signedPayload)
    .digest('hex');
  return `t=${timestamp},v1=${signature}`;
}

// Usage
const signature = signWebhook(JSON.stringify(data), 'your-secret');
// Set header: X-Signature: t=1699999999,v1=abc123...
