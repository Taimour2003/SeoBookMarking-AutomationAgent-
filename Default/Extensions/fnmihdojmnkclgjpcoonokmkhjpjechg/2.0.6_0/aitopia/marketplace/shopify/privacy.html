Privacy Policy

Last updated: December 2024

Agent Marketplace ("we", "us", or "our") operates the Agent Marketplace Shopify application. This Privacy Policy describes how we collect, use, and share your information when you install and use our application.

1. Information We Collect

Store Information

When you install our app, we collect:

  • Store domain (e.g., your-store.myshopify.com)
  • Store name and email address
  • Store currency and timezone
  • Shopify access token (encrypted at rest)

Product Data

When you use our agents, we access:

  • Product titles, descriptions, and types
  • Product images (URLs)
  • Product tags and metadata

Usage Data

We track:

  • Which agents you use
  • Number of agent runs per month
  • Processing timestamps
Important: We do NOT collect or store customer personal data, payment information, or order details beyond what's needed for agent processing.

2. How We Use Your Information

We use the collected information to:

  • Provide AI agent services (image processing, content generation)
  • Track usage against your subscription limits
  • Process billing through Shopify's billing system
  • Send important service notifications
  • Improve our services

3. Data Sharing

We share data with:

Provider Purpose Data Shared
Replicate Image processing Product image URLs
Anthropic Content generation Product descriptions/titles
OpenAI Content generation Product descriptions/titles

All providers are bound by data processing agreements.

4. Data Retention

  • Store data: Retained while app is installed, deleted within 30 days of uninstall
  • Usage logs: Retained for 90 days
  • Processed images: Not stored (URLs passed directly to providers)

5. Your Rights (GDPR)

If you're in the EU/EEA, you have the right to:

  • Access your data
  • Request data deletion
  • Request data portability
  • Object to processing

Contact us at privacy@agent-marketplace.example.com to exercise these rights.

6. Data Security

We protect your data using:

  • AES-256-GCM encryption for access tokens
  • TLS 1.3 for all data in transit
  • SOC 2 compliant hosting infrastructure
  • Regular security audits

7. Changes to This Policy

We may update this policy. Significant changes will be communicated via email or in-app notification.
