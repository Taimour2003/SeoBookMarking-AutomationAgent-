# English dictionary (DICTIONARY_EN)

English definitions for the terms translated in the localized dictionaries
(for example `lv/DICTIONARY_LV.md`). Definitions describe each term in the
context of the web scraping browser extension.

Placeholder words (kept untranslated across locales): `Sitemap`, `Sitemaps`,
`Web Scraper`, `Web Scraper Cloud`, `Cloud`, `CSS`, `HTML`, `JSON`, `Regex`,
`Proxy`, `Log-in`, `Dropbox`, `Google Drive`, `S3`.

| English                    | Definition                                                                                                                                       |
|----------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------|
| web data extraction tool   | A tool that collects structured data from web pages through a point-and-click interface.                                                         |
| Advanced $sitemap$ builder | The full-featured editor for creating and configuring sitemaps manually. It is a scondary UI in extension that unlocks full customization        |
| data extractor             | A configured instruction that pulls a specific piece of data from a page.                                                                        |
| wizard                     | A guided, step-by-step flow for building a scraping configuration.                                                                               |
| developer tools            | The browser's built-in developer tools panel where the extension runs.                                                                           |
| select                     | To pick an element on the page by clicking on it.                                                                                                |
| re-select                  | To pick the element or links again, replacing the previous selection.                                                                            |
| pagination                 | Navigation across multiple result pages (next page, numbered pages, load more).                                                                  |
| scroll                     | Scrolling the page to load additional content, such as infinite scroll.                                                                          |
| data                       | The information extracted from web pages.                                                                                                        |
| next page button           | The control on a site that loads the next page of results.                                                                                       |
| parent selector            | A selector that is the direct parent of the current selector. Selectors are organized in a tree-like data structure.                             |
| child selector             | A selector that is a direct child of the current selector. Selectors are organized in a tree-like data structure.                                |
| hover                      | To move the cursor over a page element without clicking it, for example to highlight the element the picker will select.                         |
| Regex                      | A regular expression used to match or extract specific text patterns.                                                                            |
| click                      | To trigger a click on a page element, used for pagination or actions.                                                                            |
| click element              | The element that is clicked to load more content or perform an action.                                                                           |
| link                       | A URL reference to another page, used to navigate to item pages.                                                                                 |
| website                    | The site being scraped.                                                                                                                          |
| scheduler                  | A Cloud feature that runs scraping jobs automatically on a schedule.                                                                             |
| schedule                   | To set up automatic, recurring data extraction runs.                                                                                             |
| scrape                     | To extract data from a page.                                                                                                                     |
| scraper                    | The configuration or engine that performs the data extraction.                                                                                   |
| scraping                   | The process of extracting data from web pages.                                                                                                   |
| extension                  | The browser extension or add-on that provides the scraping functionality.                                                                        |
| selector                   | A configuration element that identifies and extracts specific data from HTML elements on a web page.                                             |
| attribute                  | An HTML attribute of an element (for example href) used as a data source.                                                                        |
| element                    | A single element on the web page.                                                                                                                |
| bot detection              | Mechanisms websites use to detect and block automated scraping.                                                                                  |
| input                      | A form input field for entering a value.                                                                                                         |
| CSS Selector               | A pattern used to select HTML elements on a web page for data extraction, customizable in the tool's interface.                                  |
| domain                     | The domain name of the website being scraped.                                                                                                    |
| Select selector            | A control for choosing an element on the page to create a selector.                                                                              |
| URL                        | The web address of a page.                                                                                                                       |
| sitemap                    | A structured configuration in the web scraping tool that defines how to navigate and extract data from a website.                                |
| item page                  | A page containing the details of a single record, reached by following a link.                                                                   |
| ID                         | A unique identifier, for example a sitemap or selector ID.                                                                                       |
| multiple                   | Indicates that a selector can extract more than one record or value.                                                                             |
| sleep                      | An action that pauses execution for a set duration.                                                                                              |
| ms                         | Milliseconds, the time unit used for delays and intervals.                                                                                       |
| data extraction            | The process of collecting structured data from web pages.                                                                                        |
| data point                 | A single extracted value found on a page.                                                                                                        |
| experimental features      | Optional, in-development features that can be enabled in the settings.                                                                           |
| point-and-click interface  | A user-friendly visual interface that allows users to select elements on a web page by clicking rather than writing code.                        |
| usage metric gathering     | The collection of anonymized, aggregated statistics about how users interact with the extension to improve the product.                          |
| AI                         | Artificial intelligence features used to analyze pages and suggest data extraction.                                                              |
| record                     | A single extracted row or item of data shown in the data preview.                                                                                |
| enable                     | Turn a feature or option on.                                                                                                                     |
| disable                    | Turn a feature or option off.                                                                                                                    |
| browser                    | The web browser that runs the extension.                                                                                                         |
| Website State Setup        | A configuration view for setting up a predefined website state, for example logging in, before data extraction starts.                           |
| limit                      | A maximum count, for example the maximum number of elements to extract.                                                                          |
| action                     | A configured operation the scraper performs, for example clicking or waiting.                                                                    |
| tab                        | A browser tab.                                                                                                                                   |
| deprecated                 | A feature that is obsolete and will be removed in a future release.                                                                              |
| setup                      | A configuration step or screen, for example data setup or website state setup.                                                                   |
| Privacy Policy             | The legal document describing how user data is handled.                                                                                          |
| follow item links          | To open each selected item link and extract data from the linked page, like a crawler navigating to pages. Not tracking or monitoring.           |
| title                      | The name of a linked item, shown as a table column next to the link URL. Not a document heading or page title.                                   |
| preview                    | An advance look at the data or elements a selector will extract, shown before running a full scrape. Not verification or confirmation.           |
| discard                    | To exclude elements from the extracted results, for example elements present before clicking. Not cancelling an action or unsaved changes.       |
| review                     | To write a public rating with comments about the extension on the browser web store; also such a user-written rating. Not to inspect or examine. |
| key                        | A unique identifier for a data point, used in the extracted results. Not a physical key or password. For example JSON object key                 |
| auto                       | Automatically, without user intervention. Not a physical car or vehicle.                                                                         |
| refresh                    | A button that reloads or updates the data table or page content, for example refreshing the data preview.                                        |
